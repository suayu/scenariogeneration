# E1 五组 100 场对比：实现与验证记录

更新：2026-10-12。当前分支 RiskWeaver-dev；没有提交 GitHub。工作区 `/home2/zhaoyx/scenario-dreamer`。

## 本轮实现的五项修改

1. **SAFE-SIM 对抗引导恢复**：新增 `policies/safe_sim_official_guidance.py`，直接调用上游真实 Collision、TTC、CauseCollision 损失；自车是仅参与损失的固定虚拟行，扩散不控制自车。`diffusion_model_wrapper.py` 仅增加显式 manual 模式注册与目标识别两个修改点。原 `guidance.mode=default` 保留，可在独立新实验中回退；不静默切换。
2. **公共指标**：新增 `experiments/comparison/e1_metrics.py`。基于实际执行状态计算固定航向、恒速 OBB 首次接触 TTC，保留旧中心点 TCA；D 定义不变，明确标注旧 TCA 输入。EA 仅统计实际完成状态转移的帧，采用已有 empty-set-zero-v2 协议。碰撞速度使用接触前最后观测速度，记录自车速度、对方速度及向量相对速度。保存路线偏离和投影进度。
3. **STRIVE 一致性审计**：沿用官方权重、75 次初始化、300 次对抗优化、300 次解优化与真实自车策略回调，10 帧重规划。记录从真实当前状态至插值未来的速度、加速度、jerk、偏航率；不通过修改轨迹或减少优化预算来改善基线结果。完整联合候选和执行前缀继续通过 OBB 检查。
4. **完整失败统计**：新增公共运行器 `run_e1_group.py`，区分生成失败、运行失败、规划服务失败、预测服务失败和预测覆盖不足。保留部分执行后的碰撞，不把未执行场景当无碰撞正常结果。报告预定分母、已尝试数、实际执行数和正常结束数；D 无有效帧为 null，失败不筛除。候选轨迹与修正后待执行轨迹分开记录。
5. **复用与并行**：新增 `e1_protocol.py`、`launch_e1_five_arm.py`、`e1_reporting.py`。按场景分片分配空闲 GPU，单场内部保持联合一致，不拆车辆；不终止其他 GPU 任务。自动保存冻结清单、源文件哈希、配置、种子、PID、日志、attempt JSON、执行/预测 trace、包含终止帧的视频、完整 CSV 与配对 bootstrap 区间。

## 五组统一配置

- RiskWeaver 纯动态、画像关；RiskWeaver 纯动态、画像开；Scenario Dreamer；SAFE-SIM 适配；STRIVE 适配。
- 自车 IDM，基础 seed=42；每场种子由冻结全局编号导出，分片不改变种子。
- 自然终止或最多 400 帧，不固定截断到 100/200 帧。
- 从冻结 250 场按来源独立于性能抽取 100 场：既有75中30场、首批LDM55中22场、扩展LDM120中48场。五组共享同一清单，共500次预定尝试。
- 两组 RiskWeaver 同一模型、最多4次规划；inner_lr=0.2、inner_beta=0.5、n_guide_steps=2 固定。两组同样启用连续动力学修正、AnchorDrive式锚点引导；候选扩展关闭、后车加速扩展为空。仅 profile_enabled 不同。
- 两组画像/策略知识从每场开始初始化，使用该场全部已观测驾驶历史，禁止测试场景间或 GPU 分片之间泄漏历史。因此本轮比较是完整画像候选排序链路 vs 自由离散规划，并不能单独证明画像历史因子的因果贡献。
- 不同方法沿用自己的目标和正则；RiskWeaver 的动力学/正理论可达区域门控额外披露。公共背景 OBB 审计不代表连续时间无碰撞保证。

## 指标解释与可比范围

- 主比较：碰撞率及预定尝试碰撞产出率、OBB TTC、EA、接触前碰撞速度、路线偏离率、完成率、进度、生成失败、运行开销与背景碰撞。
- 无7秒内接触的 TTC 保存 null 与明确的无接触标记，不用零代替。另保存7秒截尾 TTC，有限值均值同步披露样本数及无接触数。
- 可行驶区域有两种不同概念：全图中心线走廊面积只是栅格道路代理；受预测交通影响的动力学可达终端面积来自公共可达性评估器，不能称真实道路多边形面积。
- SAFE-SIM **实际执行为 diffusion**；公共可达性未来来自复制 CtRL-Sim 状态的 persistent 代理滚动。RiskWeaver/STRIVE 使用各自原生联合未来。Scenario Dreamer 原生接口无对齐联合未来时 D/可达面积为 null。因此这些 D 不能直接跨来源合并排名。预测覆盖率/无效原因始终披露。
- 250 场有开发使用历史，本100场为中等规模开发比较，不标为未见测试集泛化结论。
- STRIVE 原权重来自 nuScenes，当前采用 Waymo 车道走廊地图代理、CV 初始化未来和 0.5→0.1 秒插值；保留跨域保真限制，不标为完整原论文复现。
- SAFE-SIM 虚拟自车采用外部恒速未来和合成直线中心线，当前跑完整扩散而非原论文全部 partial-diffusion proposal 流程；官方损失桥属于公开适配基线，仍需对照原论文配置做保真验证。

## 可复用命令

在服务器工作区执行；模型名、policy 和 manifest 可替换，输出目录必须是新的：

```bash
PYTHONPATH=.:safe-sim:safe-sim/trajdata/src \
/home2/zhaoyx/miniconda3/envs/scenario-dreamer/bin/python \
experiments/comparison/launch_e1_five_arm.py \
  --manifest experiments/scenario_dreamer_ldm_expand250_20260928_r1/riskweaver_frozen_250_scenes.json \
  --output-dir /home2/zhaoyx/scenario-dreamer/experiments/<new_run> \
  --policy idm --model qwen3.8-flash --gpus 0,1,2,3 --shard-size 10
```

默认五组各一场冒烟，通过才进入100场。只运行不调用LLM的三基线冒烟可加：
`--smoke-only --smoke-groups scenario_dreamer,safe_sim,strive`。
单方法复用同一 runner 的 `--group --manifest --output-dir --policy --model`；SAFE-SIM评估源可显式选择 `--evaluation-source native`，单独保存回退结果。禁止静默混用。
